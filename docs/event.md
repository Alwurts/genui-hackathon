## Premise
Build agents that **render** complete, interactive interfaces — not chat. Forms, dashboards, approval flows, full apps — generated from agent output. No pitches, no panels, no chat-wrappers. Working code over slides.

## The four judging tracks
1. **Dynamic Component Generation** — UI structure/state adapts to the model's reasoning.
2. **Agentic Feedback Loops** — users steer autonomous agents through interactive visual elements.
3. **Latency-Optimized Rendering** — KV cache tricks or local execution (Gemma 4, Muse Spark) for zero-lag UX.
4. **Tool-Enabled Interfaces** — UI exposes interactive hooks for agents to drive cross-app workflows.

## Stack / protocols
- **A2UI** (Google, Apache-2.0) — open protocol for agents to emit interactive components.
- **AG-UI** (CopilotKit) — protocol connecting AI agents to frontend UIs.
- **CopilotKit** — React framework for embedded copilots; AG-UI transport + MCP client; v1.5 ships durable long-running agents.
- **MCP Apps** — Model Context Protocol applications rendered as interactive UI.
